# Tony's Chocolonely (https://tonychocolonely.com) - BRIEF
Impact chocolate. **Shopify** custom theme (`ap.main.js`), Sentry.
- Fonts: **"Chocolate letter"** (custom chunky hand-cut, enormous headlines) + **American Typewriter** (bold, everywhere). Free approx: **Rubik Mono One/Rammetto One/"Bowlby One SC"** + **"Special Elite"/"Courier Prime"** (or Zilla Slab).
- Palette: Tony blue `#3053A4`, signal red `#D91F26`, yellow `#FFE200`, mint `#7BE9E3`, orange `#FF7400`, green `#78C828`; each bar flavour has its own wrapper colour.
- Style: **deliberately "wonky"** - tilted rotated cards, paper-cut sticker modals (country selector tiles skewed at different angles), grey-red giant slogan type ("CRAZY ABOUT CHOCOLATE / SERIOUS ABOUT PEOPLE"), news cards on mission (cocoa scorecard).
- Steal: tilted sticker UI, mission slogan as giant type, wrapper-colour system, deliberate imperfection.
